# Case file format

Write the case file in Markdown with exactly these sections:

## Household
One line per person: age, role (e.g. "grandparent"), working or not. Then: monthly household income,
household size, per-capita income (show the sum), residency.

## Schemes
A table with one row per scheme checked:

| Scheme | Eligible | Why | Amount | Next step |
|---|---|---|---|---|

## Actions taken
Appointments booked or applications submitted, with their reference numbers. Write "None" if none.

## Open questions
Facts that were missing or unclear. Write "None" if none.
