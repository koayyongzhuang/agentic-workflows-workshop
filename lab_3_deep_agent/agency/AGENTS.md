# Agency house rules

These rules apply to every case. They are loaded into the agent's system prompt on every run.

- Write for a caseworker, not for the citizen: short, factual, no reassurance.
- Always show the per-capita income calculation: monthly household income ÷ household size.
- Quote amounts exactly as the scheme rules state them, with the [source] file.
- Never store or repeat identity numbers. Refer to the household as "the household".
