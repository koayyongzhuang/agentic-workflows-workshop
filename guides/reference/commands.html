Lab guides/Reference

Reference

Commands

Every command the guides use, in the order you'll need them.

Two places to type

Laptop terminal: a normal terminal in the repo folder. All make commands run here.
Container shell: open it with make shell. All python -m commands run here.

Set up and check

Laptop terminal

make upBuild and start the database, the Mock Gov API and the workshop container.
make checkPre-flight check of the model, tool calling, API, RAG and memory. Every line should be green.
make shellOpen the container shell.
make logsFollow the containers' logs when something won't start.
make downStop everything at the end of the day.

make multiChat with the Citizen Services Platform. You approve bookings.
make testRun the offline test suite after you change code.
make tracesSuccess rate, response time and most-used tools across your runs.
make serveServe the platform as an HTTP API on port 8080.

The P= value is the same as the pattern's Studio graph name and file name. Plain make patterns runs all five in a row.

When something goes wrong

Dollar signs

Wrap questions in single quotes. In double quotes the shell turns $2,400 into ,400.

Don't pass dollar amounts through make … ARGS= either: make expands $ too. Use the container shell instead.

You seeDo this
"LLM responds" fails in make checkFix MODEL or the API key in .env, then run make up so the container reloads it.
service "workshop" is not runningRun make up. If it still stops, read make logs.
Prompt changes do nothingYou're on MODEL=mock, which ignores prompts. Switch to a real model.
Studio won't connectUse Chrome, sign in to LangSmith, and keep make studio running. Still stuck? Skip Studio; the terminal shows the same path.
The wifi is downSet MODEL=mock in .env. Every graph still runs offline.
