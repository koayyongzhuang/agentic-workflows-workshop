STACK workshop · hands-on labs

From Chatbots to Agents

Step-by-step guides for the two hands-on sessions. Each takes you through one lab or one pattern: run it, predict what it will do, check, change one thing, and test yourself.

Before you start

In the repo folder, run make up, then make check. Every line should show a green ✓. Docker or Podman both work. The labs run in Studio: run make studio, then open it in Chrome. No Studio? Every step has a "No Studio? Use the terminal instead" box with the terminal version (make single, make multi or the container shell).

Session 1 · 40 minutes

  1. Lab 1 Single Agent 40 min A tool-using helpdesk agent. Read its trace, then change its prompt, its tools and its role.

Session 2 · 40 minutes

  1. Pattern 1 Sequential Pipeline Assembly Line 6 min A fixed chain of stages, each writing one field of the state.
  2. Pattern 2 Orchestrator Concierge 6 min One agent classifies the request and hands it to a single desk.
  3. Pattern 3 Parallel Fan-Out / Gather Octopus 7 min Reviewers run at the same time; a synthesizer merges their feedback.
  4. Pattern 4 Hierarchical Decomposition Russian Doll 7 min A planner splits a goal; one worker graph runs per sub-task.
  5. Pattern 5 Generator & Critic Editor's Desk 6 min Write, check against criteria, revise, with a cap on rounds.
  6. Lab 2 Citizen Services Platform 25 min A supervisor, three specialists and five guardrails. Approve a booking, then add a fourth agent.

Short on time in Session 2? Do any two patterns, then the platform. The rest make good take-home work.

Keep these open

  • Commands: every make and python -m command, Studio graph names, and fixes for common errors.
  • Patterns sheet: the five patterns on one page, with the names the readings use.
  • Glossary: one meaning per word, used in every guide.

How each guide works

Each guide opens with what you'll be able to do by the end, explains just enough to do it, then gives numbered steps. Before you run something, the guide asks you to predict the result; open the box only after you've guessed. Committing to a guess before you look helps you remember the answer. Tick each step as you finish it; your browser remembers the ticks.

Every guide ends with a three-question quiz, one primary source to read later, and a reminder that you can ask: a facilitator, the person next to you, or your AI assistant.

All schemes, policies and data in the labs are fictional and exist only for teaching.
