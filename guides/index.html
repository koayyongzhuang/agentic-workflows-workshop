STACK workshop · hands-on labs

From Chatbots to Agents

Step-by-step guides for the two hands-on sessions. Each takes you through one lab or one pattern: run it, predict what it will do, check, change one thing, and test yourself.

Before you start

Do this once, before your first session. It takes about 10 minutes, most of it the first build.

  1. Install the tools

    Open the box for your laptop. Everyone also needs:

    • A web browser and a free LangSmith account, for Studio. Sign in once before the session.
    • A Bifrost API key for the workshop’s model gateway. Collect yours at stack.asean-lab.com.
    macOS
    1. A container engine, either one:
      • Docker Desktop. Start it once so it's running.
      • Podman Desktop, free. Its first-run setup installs Podman and creates a Podman machine. Then open Settings → Resources, click Setup on the Compose tile and follow the prompts (how).
    2. make: in Terminal, run xcode-select --install. If it says the tools are already installed, you have it.
    3. Use the Terminal app for every command in the guides.
    Windows 10 or 11
    1. A container engine, either one. Both set up WSL 2, the Linux layer they run on, if your PC doesn't have it yet.
      • Docker Desktop. Start it once so it's running.
      • Podman Desktop, free. Its first-run setup installs Podman and creates a Podman machine. Then open Settings → Resources, click Setup on the Compose tile and follow the prompts (how).
    2. make and Git: open PowerShell and run the two commands below. Then close PowerShell and open a new one, so it finds them. 
      winget install ezwinports.make
winget install Git.Git
    3. Use PowerShell (or Windows Terminal) for every command in the guides. The make commands work the same as on a Mac.

    Clone the repo with Git rather than downloading a ZIP: the repo tells Git to keep Unix line endings, which the containers need.

    Linux
    1. A container engine, either one:
      • Docker Engine with the Compose plugin (docker compose). Then follow the post-install steps so you can run docker without sudo, and log out and back in.
      • Podman 4.7 or newer, plus podman-compose, so that podman compose works. Or Podman Desktop, then Settings → Resources → Compose → Setup.
    2. make and Git from your package manager, for example on Ubuntu or Debian: 
      $ sudo apt install make git
    3. Use your usual terminal for every command in the guides. The make commands work the same as on a Mac.

    Can't install Docker or Podman? Follow Run the labs without containers instead. It replaces steps 1 to 4 here, and Labs 1 to 3 work the same.

  2. Create your settings file

    Open a terminal in the repo folder (Terminal on a Mac, PowerShell on Windows, your usual terminal on Linux) and copy the example settings file:

    $ cp .env.example .env

    Open .env in any editor (for example open -e .env on a Mac, notepad .env on Windows, nano .env on Linux) and fill in these two lines. Leave everything else as it is.

    BIFROST_API_KEY=paste-your-bifrost-key-here
LANGSMITH_API_KEY=paste-your-langsmith-key-here
    • BIFROST_API_KEY is your key for the workshop’s model gateway. Collect it at stack.asean-lab.com.
    • LANGSMITH_API_KEY comes from your LangSmith account: sign in at smith.langchain.com with your personal account, then open Settings → API Keys.
    • Your keys stay in .env on your laptop. Don't paste them into a chat, a screenshot or a commit.

    No key, or the wifi is down? Change the line to MODEL=mock. Every graph still runs offline, but the mock model ignores prompts, so Lab 1's prompt exercises need a real model.

  3. Start the stack and check it
    $ make up
$ make check

    The first make up builds the containers and takes a few minutes. Every line of make check should show a green ✓. If "LLM responds" fails, fix MODEL or the key in .env, then run make up again so the container reloads .env.

  4. Open Studio
    $ make studio

    Leave it running in its own terminal, then open https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024 in your browser. You should see the graph list, starting with lab_1_single_agent. The labs run here.

    Your browser may ask permission to let the page connect to your local server — click Allow. If you dismiss or block it by mistake, reloading the tab won't ask again: fully quit the browser (Cmd+Q on Mac, or close every browser window on Windows and Linux), reopen it, and enter the Studio URL again so the prompt reappears. Safari can't connect to the local server, so use another browser.

    No Studio? Every step in the guides has a "No Studio? Use the terminal instead" box with the terminal version (make single, make multi or the container shell).

    Doing the optional Labs 3 and 4? Lab 4 runs Hermes Agent inside the workshop container. If you built the containers before Lab 4 was added, run make up-build once to add it.

Session 1 · Single Agent Hands-On · 50 minutes

  1. Lab 1 Single Agent 50 min A tool-using helpdesk agent. Read its trace, change its prompt, its tools and its role, then add a new scheme.

Session 2 · Multi-Agent Hands-On · 60 minutes

  1. Pattern 1 Sequential Pipeline Assembly Line 6 min A fixed chain of stages, each writing one field of the state.
  2. Pattern 2 Routing Concierge 6 min One agent classifies the request and hands it to a single desk.
  3. Pattern 3 Hierarchical Decomposition Russian Doll 7 min A planner splits a goal; one worker graph runs per sub-task.
  4. Pattern 4 Parallel Fan-Out / Gather Octopus 7 min Reviewers run at the same time; a synthesizer merges their feedback.
  5. Pattern 5 Generator & Critic Editor's Desk 6 min Write, check against criteria, revise, with a cap on rounds.
  6. Lab 2 Citizen Services Platform 25 min A supervisor, three specialists and five guardrails. Approve a booking, then add a fourth agent.

After the workshop · optional · about 40 minutes

The wrap-up introduces the agent harness; these two labs let you try one. The same agency again, now on ready-made harnesses: the loop, memory, files and tools around a model that you wrote yourself in Lab 1. Lab 3 is a harness you build on in code and ship inside your app. Lab 4 is a harness you run as a product and connect your systems to.

  1. Lab 3 Deep Agent 20 min LangChain's Deep Agents writes a household case file: it plans, delegates each scheme to a sub-agent, asks before booking, and follows your skill.
  2. Lab 4 Hermes Agent 20 min A ready-made assistant in your browser. Connect the agency's tools, teach it your preferences and a skill, then have it change the workshop code.

How each guide works

Each guide opens with what you'll be able to do by the end, explains just enough to do it, then gives numbered steps. Before you run something, the guide asks you to predict the result; open the box only after you've guessed. Committing to a guess before you look helps you remember the answer. Tick each step as you finish it; your browser remembers the ticks.

Every guide ends with a three-question quiz, one primary source to read later, and a reminder that you can ask: a facilitator, the person next to you, or your AI assistant.

All schemes, policies and data in the labs are fictional and exist only for teaching.
