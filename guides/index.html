STACK workshop · hands-on labs

From Chatbots to Agents

Step-by-step guides for the two hands-on sessions. Each takes you through one lab or one pattern: run it, predict what it will do, check, change one thing, and test yourself.

Before you start

Everyone gets their own lab desktop: a Linux computer in the cloud that opens in a browser tab, with VS Code, Chrome and the workshop code already installed. Nothing to install on your laptop. Setup takes about 5 minutes.

You need your key card from the facilitators, a laptop with a current browser (Chrome, Edge, Firefox or Safari), and a free LangSmith account for Studio. Running the labs on your own laptop instead? Follow the local setup guide.

  1. Unlock and copy your API key

    Your key card has a ten-character code, such as ABCDE-23456, and a QR code. On your laptop, do the following:

    1. Scan the QR code on your card, or open stack.asean-lab.com.
    2. Type the code from your card into Card code and click Unlock key. The dash is optional.
    3. Click Copy key. If your browser blocks copying, the page selects the key for you: press Cmd+C on a Mac or Ctrl+C on Windows.

    This is your Bifrost API key for the workshop’s model gateway. Keep the STACK web page open: you'll paste the key in step 3, and you can copy it again from there.

    Each key has its own budget and is switched off after the workshop. Code doesn’t work, or lost your card? Ask a facilitator.

  2. Open your lab desktop

    On the same STACK web page, under your key, click Open my lab desktop. Your lab desktop opens in a new browser tab.

    • It can take about 2 minutes to start. When it's ready, VS Code opens with the agentic-workflows-workshop folder.
    • The first time it loads, the desktop may ask you for a password. You don't need one: click Cancel.
    • The workshop code is already there, so there's nothing to clone or download.
    • No new tab? Your browser may have blocked the pop-up. Allow pop-ups for stack.asean-lab.com and click the button again.
    Working in the lab desktop. It's a Linux desktop, so use Ctrl for shortcuts inside it, even on a Mac: Ctrl+V to paste, Ctrl+S to save. Your laptop's clipboard works in both directions.

    Closed the tab by mistake? Go back to the STACK web page, unlock your key again and click Open my lab desktop. You get the same desktop, with your files and saved changes. If the button shows an error, ask a facilitator.

  3. Create your settings file

    Everything from here happens inside your lab desktop. Open a terminal in VS Code: in the menu bar at the top, click View, then Terminal (shortcut Ctrl+`). A terminal panel opens at the bottom, already in the agentic-workflows-workshop folder. Copy the example settings file:

    $ cp .env.example .env

    In VS Code's file list on the left (the Explorer), click .env to open it. You'll fill in two lines. Leave everything else as it is.

    BIFROST_API_KEY=paste-your-bifrost-key-here
LANGSMITH_API_KEY=paste-your-langsmith-key-here

    Your Bifrost key. Click straight after BIFROST_API_KEY= and press Ctrl+V to paste the key you copied in step 1, with no spaces or quotes. Nothing to paste? Copy it again on the STACK web page. Then click Hide from screen on the STACK web page.

    Your LangSmith key lets Studio and tracing use your LangSmith account. Create it in the lab desktop's Chrome, or on your laptop and paste it across:

    1. Sign in at smith.langchain.com with your personal account, then open Settings → API Keys and create a new API key.
    2. Fill in the Create an API Key form as in the picture below:
      • Description: anything that reminds you what it's for, such as STACK workshop.
      • Key Type: Personal Access Token, the default. Not Service Key or Tracing Only.
      • Default Workspace: leave it as it is.
      • Expiration Date: 30d covers the workshop; 90d is fine too.
    3. Click Create API Key and copy the key straight away. It starts with lsv2_pt_ and is shown only once. If you lose it, create another.
    4. In .env, paste it straight after LANGSMITH_API_KEY=, with no spaces or quotes.

    Save .env with Ctrl+S. Your keys stay in your lab desktop. Don't paste them into a chat, a screenshot or a commit.

  4. Start the stack and check it

    You run the workshop's commands in VS Code's terminal. If the terminal from step 3 is still open at the bottom of VS Code, use it. If not, open one: in the menu bar, click View, then Terminal.

    The terminal opens in the agentic-workflows-workshop folder, so you can run the commands straight away. If you're ever unsure, run pwd: the path should end in agentic-workflows-workshop.

    $ make up
$ make check

    make up starts the workshop's containers; it takes a few seconds. Every line of make check should show a green ✓. If "LLM responds" fails, check the key in .env, save it, then run make up again so the container reloads .env.

  5. Open Studio

    Studio needs its own terminal. In VS Code's menu bar, click Terminal, then New Terminal (or click + at the top right of the terminal panel). Start Studio in the new terminal:

    $ make studio

    Leave this terminal running for the whole session: closing it or pressing Ctrl+C stops Studio. Switch between terminals with the list on the right of the terminal panel, and use the first one for other commands.

    Then, in the lab desktop's Chrome, open https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024 and sign in to LangSmith. You should see the graph list, starting with lab_1_single_agent. The labs run here.

    Chrome may ask permission to let the page connect to your local server — click Allow. If you dismiss or block it by mistake, reloading the tab won't ask again: close every Chrome window in the lab desktop, reopen Chrome, and enter the Studio URL again so the prompt reappears.

    No Studio? Every step in the guides has a "No Studio? Use the terminal instead" box with the terminal version (make single, make multi, or make shell to open the container shell).

Session 1 · Single Agent Hands-On · 50 minutes

  1. Lab 1 Single Agent 50 min A tool-using helpdesk agent. Read its trace, change its prompt, its tools and its role, then add a new scheme.

Session 2 · Multi-Agent Hands-On · 60 minutes

  1. Pattern 1 Sequential Pipeline Assembly Line 6 min A fixed chain of stages, each writing one field of the state.
  2. Pattern 2 Routing Concierge 6 min One agent classifies the request and hands it to a single desk.
  3. Pattern 3 Hierarchical Decomposition Russian Doll 7 min A planner splits a goal; one worker graph runs per sub-task.
  4. Pattern 4 Parallel Fan-Out / Gather Octopus 7 min Reviewers run at the same time; a synthesizer merges their feedback.
  5. Pattern 5 Generator & Critic Editor's Desk 6 min Write, check against criteria, revise, with a cap on rounds.
  6. Lab 2 Citizen Services Platform 25 min A supervisor, three specialists and five guardrails. Approve a booking, then add a fourth agent.

After the workshop · optional · about 40 minutes

The wrap-up introduces the agent harness; these two labs let you try one. The same agency again, now on ready-made harnesses: the loop, memory, files and tools around a model that you wrote yourself in Lab 1. Lab 3 is a harness you build on in code and ship inside your app. Lab 4 is a harness you run as a product and connect your systems to.

  1. Lab 3 Deep Agent 20 min LangChain's Deep Agents writes a household case file: it plans, delegates each scheme to a sub-agent, asks before booking, and follows your skill.
  2. Lab 4 Hermes Agent 20 min A ready-made assistant in your browser. Connect the agency's tools, teach it your preferences and a skill, then have it change the workshop code.

How each guide works

Each guide opens with what you'll be able to do by the end, explains just enough to do it, then gives numbered steps. Before you run something, the guide asks you to predict the result; open the box only after you've guessed. Committing to a guess before you look helps you remember the answer. Tick each step as you finish it; your browser remembers the ticks.

Every guide ends with a three-question quiz, one primary source to read later, and a reminder that you can ask: a facilitator, the person next to you, or your AI assistant.

All schemes, policies and data in the labs are fictional and exist only for teaching.
